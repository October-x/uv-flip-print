# 复制给支持代码执行的 AI

请读取并使用这个 GitHub 项目制作实际可打印的 UV 浮雕变画文件：
https://github.com/October-x/uv-flip-print

先阅读 README.md 和 SKILL.md，然后运行仓库里的 scripts/generate.py，不要只给我步骤，也不要用文生图模型绘制条纹效果。

我会上传两张原图：第一张对应从成品左侧观看，第二张对应从右侧观看。成品默认 50×50 mm；如我另给尺寸，以我的尺寸重新生成。浮雕高度使用工具默认 0.8 mm。

保留原图内容、比例、完整构图和内部白色细节，等比居中适配。不自动裁切、重画或去背景；已有透明 PNG 保持透明，不添加底色或棋盘格。如果我要求去背景，使用工具支持的纯色背景移除，复杂背景需先处理透明素材。

请在独立 Python 环境安装 requirements.txt，并使用新输出目录执行生成，附加 --project，交付：
1. 配套彩色图 PNG。
2. 配套灰度高度图 PNG。
3. 可在 eufyMake Studio 打开的 .empf 项目。
4. 含打印说明和参数的 ZIP。

检查文件成功生成、两图像素尺寸和方向一致，并给我真实的下载链接。附上成品毫米尺寸、自定义纹理／彩色堆高、厚度 0.80 mm 的简短打印说明。板材厚度另行测量，不能把 0.8 mm 当作板材厚度。

这些是确定性计算的打印文件，不是并排示意图或实物效果图。不要访问我的打印机或提交打印任务。如果你不能访问仓库、执行代码或交付附件，请明确告诉我具体限制，不要假装生成成功，改为提供本地运行方法。
