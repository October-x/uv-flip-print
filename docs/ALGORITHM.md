# 文件编码与原理

这是单面 UV 堆墨浮雕变画，不是柱镜光栅片背印。UV 高度图产生连续棱面，彩色图在不同坡面分配画面，侧看时通过表面投影和遮挡产生画面切换。平面普通彩印、把两图叠加，或只印黑白条纹，都不能代替这个结构。

## 尺寸

固定 1440 DPI，像素宽高按 `floor(mm / 25.4 * 1440 + 0.5)` 计算。50×50 mm 为 2835×2835 px。两图共用画布，完整原始画布等比适配、居中透明留白。5–300 mm 是程序输入范围，还受 4000 万输出像素限制，并不是所有尺寸均已试印。

## 双视图

浮雕峰值 0.8 mm，棱周期由 `round(0.8 * 2 / sqrt(3) / 25.4 * 1440)` 得到 52 px（约 0.917 mm）。每周期左右半段各 26 px，分别取左图与右图的对应列；高度由 0 升到 255 再降到 0，形成三角波。

完整周期在画布中居中，左右剩余窄边保留平面左图，高度 0，不裁去原图。竖向棱纹对应左右观看。高度图为 RGB 灰度 PNG，灰度与几何高度关联，不代表彩墨明暗。

## 三视图（实验）

周期同为 52 px：前 16 px 左坡取左图，接着 16 px 右坡取右图，最后 20 px 低槽取中图。槽底灰度 26，峰值 255。理想截面中，侧看时凸棱逐渐挡住中间槽。

相比此前宽槽试验，该方案尝试减小侧视倾角，代价是正面中图覆盖减少、可能更易串图。实际墨层形状、设备分辨率、轮廓间断和视距都会影响效果，不能把理想几何角度当作实际切换承诺。首发没有新增实物验证。

## 透明与白色

每个条纹只复制该条纹选中画面的 RGBA；不能把另一幅图补进透明区。选中像素 alpha 为 0 时，彩色隐藏 RGB 清零，高度也为 0。内部眼白等不透明白色保持不透明。透明轮廓可能切断坡面，带来残影。

## 校验边界

生成后回读 PNG，核对尺寸、1440 DPI、配对编号和 CRC；测试逐列核对颜色、透明度、灰度和边缘策略。Studio 项目嵌入同一对 PNG，按毫米设置尺寸。软件校验不等于实物打印验证，过渡角度仍可能看到混图。
